# 常见症状速查

> 带着**现象**来找，不要从头读。每条给"可能的原因"和"去哪看"。

## 跑起来 / 装载

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| 放进 `Lumi` / `Nosa` / `Project` 的模块没被执行 | **自动扫描只装载 `.lua` 文件**；检查后缀、路径，以及模块顶层是否在装载时报错（日志里会有“模块装载失败：… 层=…”的 L2） | `10-快速开始/目录与装载次序.md` |
| 写好的钩子没被调用 | 名字写错（钩子槽是**名字**，不是函数名）；或赋给了一个普通全局变量而不是那 13 个槽之一 | `90-原语与API/钩子与帧信息.md` |
| 引擎起来就退出（退出码 1） | 引导脚本在步骤 6 之前失败，或启动必需件缺失；先看日志的 L2 / L3 / L4 | `10-快速开始/目录与装载次序.md` |

## 时序 / 暂停

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| `frame` 号不动了 | 游戏处于**暂停**（暂停帧不递增帧号） | `30-时序与时间/暂停与恢复.md` |
| 暂停时整屏黑 | **引擎不画暂停背景**（B 方案），必须在 `on_render_pause` 里自己画 | `30-时序与时间/暂停与恢复.md` |
| 拖窗口时游戏还在跑 | 引擎**不**自动暂停，这是默认行为；想暂停用配方 | `30-时序与时间/配方-拖拽即暂停.md` |
| **拖完窗口游戏不跑了** | 打开了"拖拽即暂停"但没有**恢复入口** ⇒ 需要玩家显式恢复 | `30-时序与时间/配方-拖拽即暂停.md` |
| 按了 Esc 没反应 | 引擎不绑任何键；暂停/恢复是**你的脚本**调 `wag.engine.pause()/resume()` | `30-时序与时间/暂停与恢复.md` |
| 窗口失去焦点就停住 | 失焦是**默认暂停源**；CI/无头场景用 `--no-focus-pause` 启动 | `30-时序与时间/暂停与恢复.md` |
| 静置时游戏就冻住（无输入） | 同上：失焦暂停；或你的逻辑被自己的门控跳过了 | 同上 |
| 最小化后画面不更新 | **休眠帧跳过所有渲染钩子**（逻辑照跑） | `90-原语与API/钩子与帧信息.md` |
| 慢放时动作“跳一下” | 门控逻辑靠自己的计数器，`frame` 相同表示同一逻辑帧 | `30-时序与时间/时序与帧线.md` |

## 渲染

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| 画面全黑但游戏在跑 | `on_render_*` 里没画东西；每帧都会清成信箱黑 | `50-渲染/`（待写） |
| 暂停画面是上一帧残留 | 暂停帧引擎不清屏重画吗？——**会清**，所以残留说明你画的东西没覆盖 | 同上 |
| 拖动窗口时白边/黑条 | 拖拽期间由引擎补跑整帧；若仍有条带，先看是否在 `sizemove` 期间 | `00-索引` → 窗口相关 |
| 报错"在渲染相位之外被调用" | 绘制只能在 `on_render_*` 里做 | `50-渲染/绘制与层.md` |
| 画了东西但看不见 | 被后画的东西盖住（`layer`/`z` 更大 = 在上）；或 `visible=false`；或图句柄是 0 又没给 `w/h` | `50-渲染/绘制与层.md` |
| 换图后对象消失 | 用了 `replace` 之前的**旧句柄**（`replace` 后旧句柄立即失效） | `40-容器与池/对象的一生.md` |
| 暂停时想显示"冻住的世界" | 引擎不会自动拍快照；要在暂停那一刻 `wag.draw.capture_snapshot()` | `50-渲染/批量与快照.md` |

## 随机 / 复现

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| 同一个种子两局不一样 | 抽签的**次序**不同：在渲染钩子里抽、暂停帧里抽、或多抽一次 | `30-时序与时间/随机数与确定性.md` |
| 回放对不上 | 同上；另外要确认输入与帧序都被记录 | 同上 |

## 容器 / 池

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| **子弹一多进程就没了** | **池满**：一个类最多 32767 个，超过直接终止 | `40-容器与池/池与句柄.md` |
| 用了句柄进程就没了 | 句柄**已失效**（对象被 kill、或换图后用了旧句柄） | `40-容器与池/池与句柄.md` |
| 碰撞回调一次都没触发 | 本帧没声明组对，或组号（`0..255`）与容器 `group` 不匹配 | `40-容器与池/碰撞.md` |
| 报错"同一帧重复声明同一组对" | 同一帧对同一组对调了两次 `collide.check` | `40-容器与池/碰撞.md` |
| 判定位置不对 | `hit` 是个体字段；`sx/sy` 的缩放**不影响**判定 | `40-容器与池/碰撞.md` |

## 错误与诊断

| 你看到的 | 大概是 | 去哪 |
|---|---|---|
| 脚本报错了但游戏还在跑 | 钩子里的错是 **L2**：记日志 + 通知，帧结构继续 | `70-错误与诊断/`（待写） |
| 找不到 `debug/` 目录 | 没开 `--diagnostics`；且目录在 **exe 旁边**，不是当前工作目录 | 同上 |
| 数字对不上 / 想抓现场 | `--diagnostics` 会写 `session.json` / `perf_log.jsonl` / `pool_log.jsonl` / `errors.jsonl` | 同上 |
