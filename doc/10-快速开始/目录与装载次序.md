# 目录与装载次序

## 〇、你拿到的目录长这样

```
<发行包>/
├─ LuaWAG-Luminosa-ver0.1.0/     ← 运行框架（引擎 + 脚本库，**带版本号**）
│  ├─ LuaWAG.exe
│  ├─ SDL3.dll / lua51.dll
│  ├─ Luminosa/                  ← 脚本层（下面四层就在里面）
│  └─ debug/                     ← 诊断导出（开了 --diagnostics 才有）
└─ Tools/                        ← 给你用的工具（与框架**并行**）
```

**三条约定：**

| # | 约定 |
|:--:|---|
| ① | **版本写在目录名上**，不写在任何文件里。`ver0.1.0` 是**框架版本**，与引擎版本无关 |
| ② | **升级时**：同版本补丁只覆盖 `exe` / `dll`；跨版本时连 `Luminosa/{WagLib,Lumi,Nosa}` 一起换 —— 但 **`Luminosa/Project` 永远保留**（那是你的游戏） |
| ③ | **`Tools` 与框架并行**，不属于脚本层。工具独立发布也扔这里 |

> 推荐升级姿势：**解压新框架目录 → 把旧目录的 `Luminosa/Project` 拷进去 → 删旧目录**。
> 比"原地覆盖"安全：不会出现"新 exe + 旧脚本"，选错了也还能回退。

---

## 一、四个目录

```
<安装根>/Luminosa/
├─ WagLib/     引导层（引擎自带：harden / hooks / boot / vocab / load / resolve）
├─ Lumi/       官方增强库（object / rng / shader / font / drag_pause …）
├─ Nosa/       第三方增强库
└─ Project/    你的游戏
```

`<安装根>` = **exe 所在目录** = 那个 `LuaWAG-Luminosa-ver…/`。

| 目录 | 谁写的 | 你能改吗 |
|---|---|---|
| `WagLib` | 引擎 | **不改**（它负责"找到并装载下面三层"） |
| `Lumi` | 官方 | 可以用；建议不改（要改就拷到 `Project` 再改） |
| `Nosa` | 第三方 | 可以用；装进来即可 |
| `Project` | **你** | 随便 |

**引擎按路径直接读取的只有 `WagLib/init.lua`**，其余全由它组织。

## 二、装载次序

| 步骤 | 发生什么 |
|:--:|---|
| 0 | 引擎预置 13 个钩子槽为**空函数** |
| 1 | `harden`：环境封堵（必须在任何用户脚本之前） |
| 2 | `hooks`：自检"槽是不是函数" |
| 3 | `boot`：`on_game_init`（此时只能用引擎原语） |
| 4 | `vocab`：装配用户词汇（`MainFrameFunc` 之类） |
| 5 | 按层装载 `Lumi` → `Nosa` → `Project` |
| 5.5 | （临时）显式 `require("Project.main")` |
| 5.6 | 安装默认策略（拖拽即暂停；有安全阀） |
| 6 | 你的脚本调用 `wag.boot.run()` ⇒ 引擎进入帧循环 |

> **步骤 6 是显式的**：`wag.boot.run()` 之前引擎**不会**开始跑帧。
> 这也意味着"装载中途失败"与"可以开始跑"是两个不同状态。

## 三、⚠️ 当前的一个真实限制：目录枚举还没实现

引擎现在**还不会自动扫描目录**。日志里会看到：

```
[L1] 层不存在或为空，跳过：Lumi
[L1] 层不存在或为空，跳过：Nosa
[L1] 层不存在或为空，跳过：Project
```

所以**放进目录的模块不会自动执行**。眼下 `WagLib/init.lua` 是**显式 require** 的：

```lua
local ok_lumi, err_lumi = pcall(require, "Lumi.Basic.rng")
local ok_sh,   err_sh   = pcall(require, "Lumi.Basic.shader")
local ok_load, err_load = pcall(require, "Project.main")
```

⇒ **你的模块要自己 require**（至少现在如此）。等目录枚举落地，这一段会变，届时本文会更新。

## 四、怎么挂钩子

钩子槽是**13 个固定名字**，挂在 `wag.hook` 上。两种写法等价：

```lua
-- 写法一：裸全局名（经用户词汇转发到 wag.hook）
MainFrameFunc = function(info) ... end

-- 写法二：直接赋到槽上
wag.hook.on_frame_main = function(info) ... end
```

> 裸全局名来自 `vocab` 的用户词汇表（如 `MainFrameFunc` / `PauseFrameFunc` / `MainRenderFunc`）。
> 两者写的是**同一个槽**，选一种即可，别混着用。

**槽必须是函数**：赋了非函数 ⇒ 引擎内部完整性错误（L3）。

## 五、最小工程长什么样

```
<安装根>/Luminosa/
└─ Project/
   └─ main.lua        ← 定义钩子，最后调 wag.boot.run()
```

```lua
-- Project/main.lua
local M = {}

function M.main_frame(info)
    -- 每逻辑帧跑一次；info.dtg 恒为 1/60
end
MainFrameFunc = M.main_frame

wag.boot.run()   -- 请求进入帧循环
```
