# 平台给的参考系（只有一个）

> **引擎只认这一层坐标：逻辑坐标。**
> 世界怎么映射到它，是你的事（见同目录 `你自己的参考系.md`）。

---

## 一、逻辑坐标

| 项 | 值 |
|---|---|
| **原点** | **窗口中心** |
| x 轴 | 向右为正 |
| y 轴 | **向上为正** |
| 单位 | **DIP**（本平台上等于像素） |

⇒ 可见范围是 `render` 指定的矩形，**以原点为中心**：

```
左下角 = (−w/2, −h/2)
右上角 = (+w/2, +h/2)
```

所以 `(0, 0)` 永远在**屏幕中心**，与窗口多大无关。

---

## 二、可见范围（`render`）

世界的可见范围是**设计决定**，不是引擎猜的。启动时设定：

```lua
wag.space.set_viewport {
    render   = { w = 1920, h = 810 },   -- 可省略（= 保持不变）
    strategy = "letterbox",             -- **不可省略**
}
```

| 字段 | 规则 |
|---|---|
| `render` | 单位 DIP；**可省略**（省略 = 不变） |
| `strategy` | `"letterbox"` 或 `"stretch"`；**不可省略**；**区分大小写**；未定义值直接报错（不回落） |

- `letterbox`：保持比例，多余处**留黑边**；
- `stretch`：拉满窗口，**会变形**。

### 什么时候生效

> **帧末生效**：本帧设的值，从**下一帧**起起作用。

所以第一帧用的是引擎默认值（1920×1080 信箱）—— 那是刻意的：保证第一帧永远合法（可能有黑边，但不变形）。

---

## 三、单位：DIP = 像素（本平台）

- 引擎**已经**处理了 Windows 的 DPI 缩放；
- 你**不要**自己乘 DPI 系数 —— 乘了就是双重缩放；
- 引擎内部有一条断言："窗口 DIP 尺寸与像素尺寸必须相等"，不等就是有处自己乘了。

---

## 四、窗口尺寸变了会怎样

`render` **不变**。变的是"这个固定范围怎么落进窗口"：

| 策略 | 窗口变大 | 窗口变窄 |
|---|---|---|
| letterbox | 等比例放大，黑边变化 | 等比例缩小，可能出现更大黑边 |
| stretch | 拉伸填满 | 压扁 |

⇒ **你的布局按 `render` 写**，不要按窗口写。按窗口写的布局，窗口一拖就散。

---

## 五、怎么读当前值

```lua
local vp = wag.space.get_viewport()     -- 当前生效的视口
local w, h = wag.space.get_window_size()
```

> 注意：`set_viewport` 帧末生效 ⇒ 本帧 `get_viewport()` 读到的可能还是**上一帧**的值。

---

## 六、整帧像素尺寸（**只给全屏效果用**）

有时候你需要"**屏幕到底有多少像素**"—— 典型是拿一张全屏四边形去铺着色器背景。

```lua
local w, h = wag.space.get_frame_size()   -- 像素；无窗口的构建返回 0, 0
```

| 项 | 说明 |
|---|---|
| 单位 | **物理像素**（不是 DIP，不要乘 DPI） |
| 时机 | **帧开始时定格**：一帧之内值不变 |
| 它**不是** | 逻辑坐标范围 —— 那个是 `render`（默认 1920×810） |

> ⚠️ **用途边界（纪律）**：像素尺寸只用于**整屏效果**（着色器全屏四边形、全屏遮罩、截图取景）。
> **不要**用它做游戏布局 —— 布局一律用逻辑坐标；用像素布局的代码一换窗口就整体崩。

**为什么不能拿它算缩放**：从 `render` 到 `frame` 的映射是引擎的事（信箱/拉伸两种策略），
你自己再算一遍就是第二套真相。要"铺满可见区域"，让**着色器**用 `u_box`（见下）。

### 着色器侧：`u_box`

自定义片元着色器里可以拿到一个 uniform：

```glsl
uniform vec4 u_box;   // x, y, w, h —— 像素；y 以帧缓冲左下为原点
```

```glsl
vec2 uv = (gl_FragCoord.xy - u_box.xy) / u_box.zw;  // 0..1，y 向上
```

⇒ 这样无论窗口多大、是不是有黑边，背景都**正好铺满可见区域**，且不会变形。
