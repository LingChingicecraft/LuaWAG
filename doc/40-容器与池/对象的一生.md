# 对象的一生（用 `Lumi.Basic.object`）

> 你**不需要**直接用 `wag.container.*` 原语。日常用法是官方库 `Lumi.Basic.object`：
> 它负责"类 → 池"的映射、逐对象回调、以及把字段写回容器。

---

## 一、四步

```lua
local object = require("Lumi.Basic.object")

-- ① 注册一个类（一次）
object.register(1, {
    init   = function(b) end,          -- 出生时
    frame  = function(b, dt) end,      -- 每帧
    render = function(b) end,          -- 每帧（渲染钩子里）
    kill   = function(b) end,          -- 死亡时
})

-- ② 造一个（任意次）
local b = object.new(1, { img_id = img, x = 0, y = 0, vx = 0, vy = 0 })

-- ③ 每帧推进 / 绘制
object.step(dt)     -- 在 on_frame_main 里
object.draw()       -- 在 on_render_main 里

-- ④ 杀掉
object.kill(b.handle)
```

---

## 二、`new` 的参数

| 键 | 含义 | 缺省 |
|---|---|---|
| `img_id` | 图片句柄（`0` = 白纹理，配合 `sx/sy` 画纯色矩形） | `0` |
| `x` / `y` | 位置（逻辑坐标） | `0` |
| `vx` / `vy` | 速度（**引擎不积分** —— 你自己在 `frame` 里加） | `0` |
| `rot` / `sx` / `sy` | 旋转、缩放（**负 `sx/sy` = 镜像**） | `0` / `1` / `1` |
| `rgba` | 颜色 | `0xFFFFFFFF` |
| `layer` / `z` | 绘制层与层内顺序 | `0` / `0` |
| `frame` | 图集帧号 | `0` |
| `hit` | 判定形状。**给了它 ⇒ `collides = true`** | 无 |
| `group` | 碰撞组标签（`0..255`） | `0` |
| `visible` | 是否绘制 | `true` |

> **`vx/vy` 引擎不会替你加。** 移动是你自己在 `frame` 里做的：
> ```lua
> frame = function(b, dt) b.x = b.x + b.vx * dt; b.y = b.y + b.vy * dt end
> ```

---

## 三、回调里能拿到什么

`b` 是一个 Lua 表，**字段与容器字段对应**（`x / y / vx / vy / rgba / layer / z / frame / group ...`），
外加 `b.handle`（句柄）。

- `frame(b, dt)`：`dt` 是时间颗粒（恒 1/60）；
- `render(b)`：在渲染钩子里被调用 —— **只画，不要改状态**；
- `kill(b)`：容器被回收时。

---

## 四、每类一个池，容量 32767

`Lumi.Basic.object` 会给**每个类自动建一个池**（名字 `class:<类号>`）。

> ⇒ **一个类同时最多 32767 个**。超过 ⇒ **池满 = L3（进程终止）**。

要更多：拆成两个类（两个池），或者回收得更勤。

---

## 五、`replace` 与"换图"

```lua
object.replace(b, { img_id = new_img })
```

- **换图用 `replace`**，不是改 `img_id` —— 引擎先建后毁，**旧句柄立即失效**；
- `class` / `group` / `collides` **不可变**（出生时定）。

## 六、`hit` 与 `set_hit`

- 碰撞判定形状在**个体**上（`b.hit`），不在类上；
- 出生后再改判定用 `object.set_hit(b, hit)`；
- `sx/sy` 的缩放**不影响**判定（两者解耦）。

---

## 七、完整最小例子

```lua
local object = require("Lumi.Basic.object")

local IMG = 0        -- 白纹理：配合 sx/sy 画方块

object.register(1, {
    frame = function(b, dt)
        b.x = b.x + b.vx * dt
        if b.x > 640 then b.x = 0 end
    end,
    render = function(b)
        wag.draw.draw_image(b.img, 0, 0.0, b.x - 4, b.y - 4, 8, 8)
    end,
})

-- 在 GameInit 或装载后造一批
for i = 1, 100 do
    object.new(1, { x = i * 6, y = 100, vx = 40, rgba = 0xFF80FF80 })
end

function MainFrameFunc(info)
    object.step(info.dtg)
end

function MainRenderFunc(info)
    object.draw()
end
```
