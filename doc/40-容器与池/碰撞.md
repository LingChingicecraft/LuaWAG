# 碰撞

## 一、谁参与碰撞：`collides` 与 `hit`

| 字段 | 在哪定 | 能不能改 |
|---|---|---|
| `collides` | **出生时**（`new` 里给了 `hit` 就有） | **不可变** |
| `hit` | 出生时；之后可用 `object.set_hit(b, hit)` 改 | 可改 |

- 没有 `hit` ⇒ `collides = false` ⇒ **完全不进碰撞索引**；
- `sx/sy` 的缩放**不影响**判定（两者解耦）。

## 二、谁和谁查：组对由**你每帧声明**

引擎**不记忆**"哪两组该查"。每帧你自己声明：

```lua
wag.collide.check(1, 2, function(hits) ... end)
```

- `1` / `2` 是**组号**（`0..255`），对应容器上的 `group` 字段；
- 第三个参数是**回调**，本帧碰撞结束时被调用；
- **同一帧、同一组对只能声明一次** —— 声明两次是脚本错误（L2）。

> 为什么"每帧声明"：规则不持久化 ⇒ 你可以在不同帧查不同的组对（例如只在有子弹时查）。

## 三、回调收到什么

一个**扁平数组**：

```
hits = { a1, b1, a2, b2, a3, b3, ... }
```

（`a` 来自第一组，`b` 来自第二组；都是**句柄**。）

```lua
wag.collide.check(1, 2, function(hits)
    for i = 1, #hits, 2 do
        local a = hits[i]
        local b = hits[i + 1]
        -- 你自己决定怎么处置
    end
end)
```

> **引擎只报告，不处置**：不销毁、不扣血、不播放特效 —— 那些是你的逻辑。

## 四、单对象查

要查"某个对象与某组里所有的"：

```lua
wag.collide.check_one(h, group, function(hits) ... end)
```

## 五、顺序与时机

- 声明发生在**逻辑钩子**里（`on_frame_main` / `on_frame_ext`）；
- 引擎在本帧碰撞阶段统一做：**重建索引 → 宽相 → 窄相 → 每个请求一次回调**；
- 回调里**可以**杀对象（下一帧才生效的死亡请按你的规矩来）。

## 六、统计

```lua
local st = wag.collide.stats()
-- st.ms / st.requests / st.items / st.candidates / st.hits
```

只读、反映**上一帧**。用来判断"是不是碰撞把我拖慢了"。

## 七、三个常见错误

| 错误 | 症状 |
|---|---|
| 同一帧用同一组对调了两次 `check` | 脚本错误（L2），且**整条请求作废** |
| 以为引擎会替你扣血/销毁 | 不会。只给 `hits` |
| 用 `group` 当"类型" | `group` 只是**碰撞组标签**（`0..255`），不参与"是什么"的判断 |
