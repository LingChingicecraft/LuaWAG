# 图片与纹理

## 一、白纹理：`0`

`image = 0` 表示**内置 1×1 白纹理**。

配合 `sx/sy`（或 `w/h`）就能画纯色矩形 —— 不需要为每个色块建一张图：

```lua
wag.draw.draw_image(0, 10, 0.0, x, y, w, h)   -- 颜色由绘制状态决定
```

## 二、加载图片

```lua
local h = wag.image.load_from_file("name", "path/to/a.png")   -- 返回句柄
```

- `name` 是你给的**逻辑名**（后面用它查/卸）；
- 句柄是数字，**不要对它做算术、不要存盘**（见 `40-容器与池/池与句柄.md` 的同一条纪律）。

## 三、查询与卸载

```lua
local h = wag.image.lookup("name")     -- 名字 → 句柄（不存在 = nil）
local w, h = wag.image.size(handle)    -- 像素尺寸（不存在 = nil）
wag.image.unload("name")               -- 幂等：卸不存在的不算错
```

## 四、取图矩形（图集）

```lua
wag.draw.draw_image(h, layer, z, x, y, w, h, u, v, uw, uh)
```

- `u/v/uw/uh` 的单位是**纹理像素**，不是 0..1；
- 归一化由引擎在顶点着色器里做；
- **只给其中几个是错的**：要么四个都给，要么一个都不给。

## 五、⚠️ 贴图被卸载但仍在用

> 贴图被 `unload` 之后，仍有容器/绘制引用它 ⇒ **这是错误，进程终止**。

⇒ 卸载前先确认没人用它；或者干脆**不要卸载**（图片占的内存通常不值得省）。

## 六、能画什么、不能画什么

| 能 | 不能（属于库层） |
|---|---|
| 画一整张图 | 自动推进的动画状态机 |
| 画图的一部分（图集取图） | 九宫格拉伸 |
| 用帧表 + 容器 `frame` 切帧 | 粒子系统、发光、后处理链 |
| 用顶点色染色 | 字体渲染见 `50-渲染/文字与字体.md`（`Lumi.Basic.font`） |
| 画顶点/网格 | 资源生命周期见 `80-资源/纹理与图片.md` |
