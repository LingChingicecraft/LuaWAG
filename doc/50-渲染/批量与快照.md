# 批量、状态与快照

## 一、`emit_containers`：一次画完所有容器

```lua
wag.draw.emit_containers()      -- 在 on_render_main 里
```

它遍历**所有池**里存活的容器，把 `visible` 且 `img ≠ 0` 的画出来（按 `layer` / `z` 排序）。

| 它会读的容器字段 | 说明 |
|---|---|
| `x` / `y` / `rot` / `sx` / `sy` | 位置与变换（负 `sx/sy` = 镜像） |
| `rgba` | 颜色 |
| `layer` / `z` | 绘序 |
| `frame` | 图集帧号 |
| `blend` / `tex_alpha` / `vcolor` | 绘制状态（见下） |
| `visible` / `img` | 不满足就跳过 |

**什么时候用它**：大量对象、走"朴素逐对象路径"时最省事（每帧一句）。
**什么时候别用**：你需要给某些对象加额外的绘制（那就在它之后单独画，或改用 `draw_image`）。

## 二、绘制状态

三态由容器字段驱动（`blend` / `tex_alpha` / `vcolor`），也可以手动设：

```lua
wag.draw.set_state { blend = "normal", texture_alpha = "normal" }
local st = wag.draw.get_state()      -- { blend = "...", texture_alpha = "..." }
wag.draw.reset_state("blend")        -- 复位一项
wag.draw.reset_state()               -- 复位全部
```

键是**字符串**；未知键会报错。**在 `on_render_begin` 里设**是正当位置。

## 三、快照（暂停背景 / 缩略图）

```lua
wag.draw.capture_snapshot()          -- 本帧请求，present 之后拍最终输出
```

- 快照是**显式请求**的：不请求就不拍（不占每帧的整屏拷贝成本）；
- 拍的是**最终输出**（包含 letterbox / 缩放后的画面），不是内部渲染目标；\n- 拍下来之后可以用 `wag.image.load_from_snapshot(...)` 变成一张图；
- **暂停时引擎不会自动帮你拍** —— 想要"冻结画面"就在暂停的那一刻请求一次。

> 想让暂停背景"冻在世界停住的那一刻"：在 `pause()` 的同一帧里 `capture_snapshot()`，
> 然后在 `on_render_pause` 里画那张图。

## 四、绘制状态什么时候会被重置

- 每帧开始时引擎清屏并回到默认状态；
- 你在 `on_render_begin` 里设的状态对本帧有效；
- **不要**跨帧依赖"上次设的状态还留着"。
