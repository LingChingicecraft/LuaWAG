# 文字与字体

> 当前推荐使用 `Lumi.Basic.font`。  
> 旧文档里基于 `Lumi.Basic.atlas` / `wag.text` 的“先切图集再排版”路线已经不是主路径。

## 一、加载字体

```lua
local font = require("Lumi.Basic.font")
local resolve = require("WagLib.resolve")

local ok = font.load(
    "ui",
    resolve.luminosa_dir() .. "/Project/ui.ttf",
    32
)
```

参数：

```text
font.load(name, path, pixel_size)
```

- `name`：逻辑名，后续 `draw` / `measure` / `unload` 用它。
- `path`：字体文件路径；UTF-8，相对安装根或绝对路径都可以。
- `pixel_size`：像素高度；同一文件不同字号应分别加载成不同名字。

同名再次 `load` 会替换旧字体。  
文件读不到或格式不接受时返回 `false` / 失败，具体错误进日志。

## 二、画文字

```lua
font.draw("ui", "Hello", 0, 200, {
    color = 0xFFFFFFFF,
    align = "center",
    scale = 1.0,
    layer = 1000000,
    z = 0.0,
})
```

坐标语义：

```text
x        = 锚点 x（按 align 调整前）
baseline = 基线 y，世界坐标 y 向上
```

`align`：

```text
"left"    x 是左端
"center"  x 是中线
"right"   x 是右端
```

`font.draw` **只能在渲染相位调用**。  
返回实际绘制宽度（已乘 `scale`）；字体未加载时返回 `nil`。

## 三、量宽度

```lua
local w = font.measure("ui", "Hello", 1.0)
```

返回实际宽度，已经乘上 `scale`（默认 1.0）。  
用于按钮、居中对齐、打字机效果时先量再排版。

## 四、检查字形

```lua
font.has_glyph("ui", 0x4E2D)   -- “中”
```

文本是 UTF-8。  
缺字时 `draw` 会停止在该字处，不会凭空变出一个替代字形；做多语言 UI 时先查字体覆盖。

## 五、卸载

```lua
font.unload("ui")
```

幂等。  
卸载后同名 `draw` 返回 `nil`，直到重新加载。

## 六、LuaSTG 风格兼容名

```lua
font.RenderTTF("ui", "Hello", 0, 200, 0xFFFFFFFF, "center", 1.0, 1000000, 0.0)
```

参数顺序：

```text
name, text, x, baseline, color, align, scale, layer, z
```

它只是 `font.draw` 的固定参数包装，行为相同。

## 七、低层 `wag.font`

```lua
local h = wag.font.load_ttf("ui", path, 32)
wag.font.glyph(h, codepoint)
wag.font.has_glyph(h, codepoint)
wag.font.metrics(h)
wag.font.unload("ui")
```

`wag.font` 返回的是引擎字形句柄，日常游戏代码不要直接用它排版。  
除非你在写字体工具、排版库或调试器，否则用 `Lumi.Basic.font`。
