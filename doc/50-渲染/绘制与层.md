# 绘制与层

## 一、只能在这几个钩子里画

> **所有绘制必须发生在渲染相位。**

允许的钩子：`on_render_begin` / `on_render_main` / `on_render_pause` / `on_render_ext` / `on_render_end`。

在别处调 `draw_image` / `draw_vertices` ⇒ **报错 + 该调用不生效**（帧结构继续跑）。

**为什么**：绘制不是"随手写一笔"，它是**一次收集**。相位之外调 = 引擎已经收工了你还想加一笔。

## 二、`draw_image`：画一张图

```lua
wag.draw.draw_image(image, layer, z, x, y, w, h [, u, v, uw, uh])
```

| 参数 | 含义 |
|---|---|
| `image` | 图片句柄；**`0` = 白纹理**（配合顶点色画纯色矩形） |
| `layer` | 绘序层（64 位整数） |
| `z` | 层内顺序（浮点） |
| `x` / `y` | **逻辑坐标**（左上角） |
| `w` / `h` | 尺寸（逻辑单位；负值 = 镜像） |
| `u,v,uw,uh` | 可选：取图矩形，单位是**纹理像素**（不给 = 整张图） |

## 三、层与 z

```
先画 layer 小的；同 layer 内先画 z 小的
⇒ 更大的 layer / z 画在**上面**
```

| 用途 | 建议 |
|---|---|
| 背景 | layer 0 |
| 场景对象 | layer 10 |
| 特效 | layer 20 |
| HUD | layer 100 |

> `z` 只在同 layer 内比较；跨层比较没有意义（层优先）。

## 四、`draw_vertices`：一次画多个顶点

```lua
wag.draw.draw_vertices(image, {
    { x = ..., y = ..., z = ..., u = ..., v = ..., color = 0xFFFFFFFF },
    { ... }, { ... },
})
```

- 顶点按**三角形**消费（3 个一三角，或多个拼三角带）；
- `u/v` 是**纹理像素**（不是 0..1）；
- 同一次 `draw_vertices` 里的顶点共用一个 `image` ⇒ 换图 = 换一次调用。

## 五、每帧先清成信箱黑

引擎在每帧开始时把整屏清成**信箱黑**。

⇒ 你什么都不画 ⇒ **黑屏**。
⇒ 暂停帧也一样（见 `30-时序与时间/暂停与恢复.md`）。

## 六、别在绘制里改状态

`on_render_*` 只画。改状态去 `on_frame_*`。
