# 输入

> 日常游戏逻辑用 `WagLib.input` 的动作绑定；
> `wag.input` 是设备层原语，参数是 scancode。

## 一、绑定动作

```lua
local input = require("WagLib.input")

input.bind("move_left",  { keys = { "LEFT", "A" } })
input.bind("move_right", { keys = { "RIGHT", "D" } })
input.bind("jump",       { keys = { "Z", "SPACE" } })
input.bind("pause",      { keys = { "ESCAPE" } })
input.bind("fire",       { mouse = { 1 } })
input.bind("pad_jump",   { gamepad = { { device = 0, button = 0 } } })
```

`bind(action, spec)` 的规则：

- `action` 必须是非空字符串。
- `spec` 至少要有 `keys` / `mouse` / `gamepad` 之一。
- 同一个动作可以绑多个来源，查询时按 OR 合并。
- 重复 `bind` 同一个动作是**替换**，不是叠加。
- 键名在绑定时解析；写错会报错。
- `keys` 可写键名或 scancode 数字。
- `mouse` 只接受 `1..5`。
- `gamepad.device` 为 `0..7`，`button` 为 `0..25`。

```lua
input.unbind("jump")
input.clear_bindings()
```

## 二、查询

```lua
input.down("jump")       -- 本帧按住
input.press("jump")      -- 本帧按下（边沿）
input.release("jump")    -- 本帧松开（边沿）

input.mouse_pos()        -- x, y（逻辑坐标 / DIP）
input.wheel()            -- dx, dy
```

未绑定的动作会报错，不会静默返回 `false`。  
`press` / `release` 是边沿语义，`down` 是状态语义。

## 三、手柄原始查询

```lua
input.gamepad_devices()
input.gamepad_connected(device)
input.gamepad_down(device, button)
input.gamepad_press(device, button)
input.gamepad_release(device, button)
input.gamepad_axis(device, axis)
```

游戏逻辑优先用动作绑定；这些函数是给动作映射、设置界面或回放源用的。

## 四、输入源（回放）

```lua
input.set_source(source)   -- source 必须是符合契约的表
input.use_device()         -- 恢复真实设备
```

源契约包含 11 个函数：

```text
down / press / release
mouse_pos / wheel
gamepad_devices / gamepad_connected
gamepad_down / gamepad_press / gamepad_release / gamepad_axis
```

如果你的回放系统要驱动输入，必须把这些一起提供；只替换键盘会留下手柄状态不一致。

## 五、低层 `wag.input`

```lua
wag.input.down(scancode)
wag.input.press(scancode)
wag.input.release(scancode)
wag.input.mouse_down(button)
wag.input.mouse_press(button)
wag.input.mouse_release(button)
wag.input.mouse_pos()
wag.input.wheel()
```

`wag.input` 的键盘参数是 scancode，不是键名、不是字符。  
键名到 scancode 的映射在 `WagLib/keycode.lua`，由 `WagLib.input` 使用。

## 六、事件

`on_event` 的 `info.event` 是事件数组，`kind` 可能是：

```text
key_down / key_up
mouse_move / mouse_down / mouse_up
wheel
gamepad_added / gamepad_removed
gamepad_button_down / gamepad_button_up
gamepad_axis
```

字段见 `90-原语与API/钩子与帧信息.md`。
