# 字体资源

> 这里讲“字体怎么进入引擎、怎么卸”。
> 排版、对齐、基线见 `50-渲染/文字与字体.md`。

## 一、加载字体

```lua
local font = require("Lumi.Basic.font")
local resolve = require("WagLib.resolve")

local ok = font.load(
    "ui",
    resolve.luminosa_dir() .. "/Project/ui.ttf",
    32
)
```

做的事：

```text
读字体文件
交给 stb_truetype 解出字形
建立逻辑名字 → 引擎字体句柄的映射
```

注意：

- 这是**字体文件加载**，不是把整份字体一次性渲染成一张大图。
- 字形图集页由引擎按需生成/上传；页满会开新页。
- 一个字体最多 8 页；到上限后新字不再画，并记 L2。

## 二、字号

`pixel_size` 是像素高度。  
同一个文件不同字号，应该加载成不同名字：

```lua
font.load("ui_small", path, 24)
font.load("ui_large", path, 48)
```

同名再次 `load` 会替换旧字体。

## 三、支持格式

当前只承诺：

```text
.ttf
.otf
```

并且只接受：

```text
TrueType 轮廓（glyf）
CFF 轮廓
```

不是 TTC 集合，也不是 Type1。

## 四、查询与卸载

```lua
font.exists("ui")             -- 逻辑名是否存在
font.metrics("ui")            -- 字体度量
font.has_glyph("ui", 0x4E2D)  -- 某个码点有没有字形

font.unload("ui")             -- 幂等
```

`font.metrics` 返回副本，不会随引擎复用表变化。

## 五、排版与绘制

```lua
font.draw("ui", "文本", 0, 200, {
    color = 0xFFFFFFFF,
    align = "center",
    scale = 1.0,
    layer = 1000000,
    z = 0.0,
})

font.measure("ui", "文本", 1.0)
```

`font.draw` 只能在渲染相位调用。  
`baseline` 是世界坐标基线，`y` 向上；不是屏幕左上角。

## 六、缺字

字体没有某个码点时：

```text
不会凭空生成替代字形
绘制会在缺字处停止
```

多语言 UI 用 `font.has_glyph` 先检查覆盖范围。

## 七、低层 `wag.font`

```lua
local h = wag.font.load_ttf("ui", path, 32)
wag.font.glyph(h, codepoint)
wag.font.has_glyph(h, codepoint)
wag.font.metrics(h)
wag.font.unload("ui")
```

低层接口通常只给字体工具、排版库或调试器使用。  
日常游戏代码用 `Lumi.Basic.font`。
