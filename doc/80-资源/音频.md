# 音频

> 日常用 `WagLib.audio`。  
> `wag.audio` 是句柄/voice 层的低层原语。

## 一、目录与格式

```lua
local audio = require("WagLib.audio")

audio.set_dir("Luminosa/Project/seedgame/audio")
```

- 默认目录：`<Luminosa>/Project/audio/`。
- `set_dir(nil)` 恢复默认。
- 相对路径按安装根解析；绝对路径直接使用。
- 只接受 `.ogg` / `.wav`。
- 引擎第一版只接受 44100 Hz、双声道；其他格式会拒绝。

`audio.SAMPLE_RATE` 是 `44100`，用于秒 ⇄ 采样帧换算。

## 二、音乐

```lua
audio.play_music("game.ogg", {
    volume = 0.28,
    loop = true,
    loop_start = 0,
    loop_end = 108 * audio.SAMPLE_RATE,
})
```

`play_music` 默认循环。参数：

```text
volume
pan          -1 左 / 0 中 / +1 右（平衡，不是单声道折叠）
loop         默认 true
loop_start   采样帧
loop_end     采样帧
start_frame  首次播放起点（采样帧，不是中途 seek）
```

```lua
audio.pause_music()
audio.resume_music()
audio.stop_music()

audio.music_active()   -- 正在播（暂停不算）
audio.music_paused()

audio.seek_music(12.5) -- 秒
```

`seek_music` 不是真正的引擎 seek：它停掉旧 voice，用 `start_frame` 重播，  
所以切换处可能有约 38 ms 空隙。

## 三、音效

```lua
audio.play_se("se_bonus.wav", {
    volume = 0.55,
    pan = 0.0,
    loop = false,
})
```

`play_se` 默认不循环。  
音效池满时引擎会按自己的策略处理；不要把 `voice_id` 当作永久有效。

## 四、名字解析

```lua
audio.play_se("cancel")
```

不带扩展名时，依次尝试：

```text
<dir>/cancel.ogg
<dir>/cancel.wav
```

都找不到时报错，不会静默无声。

## 五、音量

```lua
audio.set_master_volume(0.8)
audio.set_music_volume(0.5)
audio.set_se_volume(1.0)

audio.get_master_volume()
audio.get_music_volume()
audio.get_se_volume()

audio.stop_all()
```

三组音量都是线性 `0..1`。

## 六、低层 `wag.audio`

```lua
local h = wag.audio.load("name", "path/a.ogg")
local voice = wag.audio.play(h, {
    volume = 0.5,
    pan = 0.0,
    loop = false,
    music = false,
})

wag.audio.stop(voice)
wag.audio.pause(voice)
wag.audio.resume(voice)
wag.audio.unload("name")
```

`wag.audio` 只认句柄和 voice；日常用 `WagLib.audio`，不要自己维护名字表。

## 七、暂停与游戏暂停

`WagLib.audio` 不会自动跟随引擎暂停。  
如果暂停时也要停 BGM，应在暂停/恢复回调里显式调用：

```lua
audio.pause_music()
audio.resume_music()
```
