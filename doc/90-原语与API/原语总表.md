# 原语总表

> 按 `src/script/primitives.cpp` 的注册点整理（2026-11-22）。
> 本表只负责“有哪些名字”。参数、返回值与限制见 `常用速查.md`；
> 高阶库（`WagLib` / `Lumi`）见对应章节。

全屏相关原语目前**不存在**，计划在 0.2.0 增加；详见 `窗口与全屏.md`。

---

## 顶层

| 名字 | 说明 |
|---|---|
| `wag.fail` | 报一条错误/警告；收表，不是字符串 |

## `wag.engine`

| 名字 | 作用 |
|---|---|
| `pause` | 请求暂停（按住 `user` 位） |
| `resume` | 请求恢复（只松 `user` 位） |
| `exit` | 请求退出（帧末生效） |
| `get_state` | 当前状态名 |

## `wag.space`

| 名字 | 作用 |
|---|---|
| `set_viewport` | 设置逻辑可见范围与缩放策略 |
| `get_viewport` | 读取只读的视口配置 |
| `set_window_size` | 请求客户区尺寸 |
| `get_window_size` | 最近一次请求值（不是实际尺寸） |
| `get_frame_size` | 当前帧缓冲像素尺寸 |

| 名字 | 作用 |
|---|---|
| `load` | 加载音频，返回句柄 |
| `unload` | 按名字卸载 |

| `stop` | 停止 voice |

| `resume` | 继续 voice |

## `wag.light`（高级/实验）

| 名字 | 作用 |
|---|---|
| `add` | 添加光源 |
| `exposure` | 设置曝光 |
| `set_space` | 设置光照覆盖的世界矩形 |
| `get_space` | 读取光照覆盖矩形 |
| `load_shader` | 加载光照着色器 |
| `band` | 设置光照带 |
| `commit` | 提交本帧光照 |
| `stats` | 读取统计 |
| `occluders.new` | 新建遮挡体池 |
| `occluders.spawn` / `write` / `kill` / `alive` | 遮挡体生命周期 |

`set_space` / `get_space` 使用世界坐标矩形：

```lua
wag.light.set_space { l = -960, b = -540, w = 1920, h = 1080 }
```

它只决定光照图覆盖的世界范围，不改变 `set_viewport` 的显示范围。
未显式设置时，首次使用取启动后的 render。

## `wag.input`

| 名字 | 作用 |
|---|---|
| `down` / `press` / `release` | 键盘（scancode） |
| `mouse_down` / `mouse_press` / `mouse_release` | 鼠标键 |
| `mouse_pos` | 鼠标位置（DIP） |
| `wheel` | 滚轮增量 |
| `gamepad_devices` | 已连接手柄列表 |
| `gamepad_connected` | 手柄是否连接 |
| `gamepad_down` / `press` / `release` | 手柄按键 |
| `gamepad_axis` | 手柄轴值 |

> 日常用 `WagLib.input` 的动作绑定；`wag.input` 是设备层原语。
