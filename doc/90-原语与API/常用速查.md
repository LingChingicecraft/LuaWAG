## 0. 一局游戏的最小骨架

```lua
local font = require("Lumi.Basic.font")
local resolve = require("WagLib.resolve")

function GameInit()
    font.load("ui", resolve.luminosa_dir() .. "/Project/ui.ttf", 32)
end

function MainRenderFunc()
    font.draw("ui", "Hello", 0, 0, {
        color = 0xFFFFFFFF,
        align = "center",
    })
end
```

`GameInit` 在层装载完成后执行一次；`MainRenderFunc` 是渲染钩子。

## 1. 引擎 / 启动

```lua
wag.boot.run()                  -- 请求进入帧循环
wag.engine.pause()              -- 按住 user 暂停位
wag.engine.resume()             -- 只松 user 位
wag.engine.exit()               -- 请求退出
wag.engine.get_state()          -- "normal" / "paused" / ...
```

`resume()` 只松 `user` 位。  
如果还有失焦、拖拽等源按着，状态仍然是暂停。

## 2. 视口 / 窗口

```lua
wag.space.set_viewport {
    render = { l = 0, b = 0, w = 1920, h = 1080 },
    strategy = "letterbox",
}

wag.space.get_viewport()
wag.space.set_window_size(1280, 720)  -- 窗口尺寸，不是 DIP
wag.space.get_window_size()      -- 最近一次请求值；不是实际尺寸
wag.space.get_frame_size()       -- 当前内部渲染目标像素尺寸
wag.space.get_output_size()      -- 当前输出 / 后缓冲像素尺寸

wag.space.set_render_size(640, 480)
wag.space.get_render_size()
wag.space.set_present_mode("letterbox" | "stretch")
wag.space.set_present_filter("nearest" | "linear")

wag.space.set_fullscreen("none" | "borderless" | "exclusive")
wag.space.get_fullscreen()
wag.space.get_display_bounds()
wag.space.get_display_work_area()
```

要点：

- `render` 是逻辑可见范围，不随窗口尺寸自动变化。
- 给 `render` 时四个字段 `l/b/w/h` 都必须存在；`w/h` 必须大于 0。
- 窗口变大只是 letterbox 黑边变化，不会让玩家看到更多世界。
- `get_window_size()` 是**请求值**，不是平台实际尺寸。
- `set_window_size` 收的是“窗口尺寸”，不是 DIP；当前平台与像素同值。
- `get_frame_size()` 是**内部渲染目标像素尺寸**；输出尺寸用 `get_output_size()`。

### 全屏

```lua
wag.space.set_fullscreen("none" | "borderless" | "exclusive")
wag.space.get_fullscreen()
```

`exclusive` 使用当前显示器原生模式；`borderless` 覆盖完整显示器边界。
全屏切换会按住 `fullscreen` 暂停源，并在失败时回退窗口模式 + L2。

详见 `窗口与全屏.md`。

## 4. 输入

### 推荐：`WagLib.input` 动作绑定

```lua
local input = require("WagLib.input")

input.bind("move_left",  { keys = { "LEFT", "A" } })
input.bind("move_right", { keys = { "RIGHT", "D" } })
input.bind("jump",       { keys = { "Z", "SPACE" } })
input.bind("pause",      { keys = { "ESCAPE" } })
input.bind("fire",       { mouse = { 1 } })
input.bind("pad_jump",   { gamepad = { { device = 0, button = 0 } } })

input.down("jump")       -- 按住
input.press("jump")      -- 本帧按下（边沿）
input.release("jump")    -- 本帧松开（边沿）
```

绑定规则：

- 同一个动作可以绑多个键/鼠标/手柄项，查询时按 OR 合并。
- 重复 `bind` 同一个动作是**替换**，不是叠加。
- 空绑定是错误。
- 键名在绑定时解析；拼错会当场报错，不会静默 false。
- `keys` 可写键名或 scancode 数字。
- `mouse` 只接受 `1..5`。
- `gamepad.device` 为 `0..7`，`button` 为 `0..25`。

`WagLib.input` 还提供：

```lua
input.mouse_pos()        -- 逻辑坐标
input.wheel()             -- dx, dy

input.gamepad_devices()
input.gamepad_connected(device)
input.gamepad_down(device, button)
input.gamepad_press(device, button)
input.gamepad_release(device, button)
input.gamepad_axis(device, axis)

input.set_source(source)  -- 回放等场景替换输入源
input.use_device()        -- 恢复真实设备
```

### 低层：`wag.input`

参数是 **scancode**，不是字符：

```lua
wag.input.down(scancode)
wag.input.press(scancode)
wag.input.release(scancode)
```

日常游戏逻辑优先用 `WagLib.input` 的动作绑定。

## 5. 音频

### 推荐：`WagLib.audio`

```lua
local audio = require("WagLib.audio")

audio.set_dir("Luminosa/Project/seedgame/audio")

audio.play_music("game.ogg", {
    volume = 0.28,
    loop = true,
    loop_start = 0,
    loop_end = 108 * audio.SAMPLE_RATE,
})

audio.play_se("se_bonus.wav", { volume = 0.55 })

audio.pause_music()
audio.resume_music()
audio.stop_music()
audio.seek_music(12.5)       -- 秒；重播实现，可能有约 38 ms 空隙
audio.music_active()
audio.music_paused()
```

名字解析：

- 不带扩展名时依次尝试 `.ogg`、`.wav`。
- 默认目录是 `<Luminosa>/Project/audio/`。
- `set_dir` 改目录；相对路径按安装根解析。
- 只支持 44100 Hz、双声道，其他格式会拒绝。

`play_music` 的 `loop` 默认 `true`；`play_se` 的 `loop` 默认 `false`。  
`pan` 是平衡（-1 左 / 0 中 / +1 右），不是把立体声折叠成单声道。

### 低层：`wag.audio`

```lua
local h = wag.audio.load("name", "path/a.ogg")
local voice = wag.audio.play(h, { volume = 0.5, music = false })
wag.audio.stop(voice)
wag.audio.unload("name")
```

`wag.audio` 只认句柄/voice；日常用 `WagLib.audio`。

## 6. 文字 / 字体

### 推荐：`Lumi.Basic.font`

```lua
local font = require("Lumi.Basic.font")
local resolve = require("WagLib.resolve")

font.load("ui", resolve.luminosa_dir() .. "/Project/ui.ttf", 32)

font.draw("ui", "文本", 0, 100, {
    color = 0xFFFFFFFF,
    align = "center",     -- "left" / "center" / "right"
    scale = 1.0,
    layer = 1000000,
    z = 0.0,
})

font.measure("ui", "文本", 1.0)
font.has_glyph("ui", 0x4E2D)
font.unload("ui")
```

要点：

- `font.draw` 只能在渲染相位调用。
- `x` 是锚点，`baseline` 是基线；世界坐标 `y` 向上。
- `align = "center"` 表示以 `x` 为中心，不是以左上角为准。
- 返回实际绘制宽度；字体未加载时返回 `nil`。
- `Lumi.Basic.font` 走 UTF-8 文本。
- 缺字会跳过/使用字体自身行为，做 UI 时请先用 `has_glyph` 检查。

低层 `wag.font.load_ttf` / `glyph` / `metrics` 一般只在工具或库层使用。

## 7. 绘制

只能在渲染钩子里调用。

```lua
wag.draw.draw_image(image, layer, z, x, y, w, h)
wag.draw.draw_image(image, layer, z, x, y, w, h, u, v, uw, uh)

wag.draw.draw_quad(image, layer, z,
    x1,y1,z1, x2,y2,z2, x3,y3,z3, x4,y4,z4)

wag.draw.draw_vertices(image, {
    { x=, y=, z=, u=, v=, color= },
    ...
})

wag.draw.emit_containers()
wag.draw.draw_glyphs(image, layer, z, flat)
wag.draw.capture_snapshot()
```

`draw_image` 的 `u/v` 是**纹理像素**，不是 0..1。  
`draw_glyphs` 每个图元 9 个数：

```text
x, y, w, h, u, v, uw, uh, color
```

绘制状态：

```lua
wag.draw.set_state { blend = "normal", texture_alpha = "normal" }
wag.draw.get_state()
wag.draw.reset_state()
```

不要手写每帧全屏清屏；渲染管线负责清屏和呈现。

## 8. 图片

```lua
local img = wag.image.load_from_file("hero", "path/hero.png")
local iw, ih = wag.image.size(img)
local same = wag.image.lookup("hero")
wag.image.unload("hero")

wag.image.define_frames(img, {
    { x = 0,   y = 0, w = 64, h = 64 },
    { x = 64,  y = 0, w = 64, h = 64 },
})
wag.image.frame_count(img)         -- 帧数；没有帧表时 nil
wag.image.anchor(img, 0.5, 0.5)    -- 归一化锚点
wag.image.anchor(img)              -- 查询 ax, ay
```

图片加载失败是资源失败（L3），不是返回 `nil` 让游戏自己猜；  
加载成功后用 `image.size` / `image.lookup` 查询。

## 9. 容器 / 池

日常用 `Lumi.Basic.object`。低层：

```lua
local pool = wag.container.new_pool("bullets")
local h = wag.container.spawn(pool, {
    x = 0, y = 0, img = image, layer = 100, z = 0,
})

wag.container.write(h, { x = 10, y = 20 })
wag.container.write_batch(...)
wag.container.set_hit(h, hit)
wag.container.replace(h, { img = other })
wag.container.kill(h)
wag.container.alive(pool)
```

统计：

```lua
wag.container.count_live(pool)
wag.container.count_live_all()
wag.container.count_occupied(pool)
wag.container.count_renderable(pool)
```

`register_class` / `set_dispatcher` 是库层接口，不是日常游戏代码。

## 11. 随机数

推荐用 `Lumi.Basic.rng` 的流对象：

```lua
local rng = require("Lumi.Basic.rng")

local R = rng.new("main")     -- main / pause / ext，或 0 / 1 / 2

R:Int(1, 6)                   -- [1, 6]，含两端
R:Float()                     -- [0, 1)
R:Bool()
R:Chance(0.3)
R:Pick({ "a", "b", "c" })
R:Shuffle(array)
R:Angle()                     -- [0, 360)，单位是度
R:Range(0.0, 1.0)
```

`Lumi.Basic.rng` 的每个函数都有“消耗几次随机数”的契约；  
要 replay 可复现，游戏逻辑不要用 `os.time`、`math.random` 或未受控外部随机源。

低层 `wag.rng` 要自己拿句柄：

```lua
local h = wag.rng.new_stream(0)   -- 0=main / 1=pause / 2=ext
wag.rng.uint32(h)
wag.rng.int(h, 1, 6)
wag.rng.float(h)

local lo, hi = wag.rng.state(h)
wag.rng.set_state(h, lo, hi)

local seed_lo, seed_hi = wag.rng.master_seed()
wag.rng.reset()
```

`master_seed()` 是读取，不是设置；句柄跨脚本重载会失效。

## 12. 日志 / 错误

```lua
wag.log.info("标题", "细节")
wag.log.warn("标题", "细节")
wag.log.emit(wag.log.level.record, "标题", "细节")
```

`wag.fail` 收表，不收字符串：

```lua
wag.fail {
    where = "检查位置",
    got = tostring(v),
    want = "0..1 的数",
}

wag.fail {
    level = wag.log.level.raise,
    where = "检查位置",
    got = "nil",
    want = "表",
}
```

默认等级是 warn，只记录不抛；要中断必须显式 `raise`。

## 14. 常见误记

| 误记 | 正确 |
|---|---|
| `draw_image` 的 `u/v` 是 0..1 | 是纹理像素 |
| `resume()` 一定回到运行 | 只松 `user` 位 |
| `get_window_size()` 是实际窗口大小 | 是最近请求值 |
| `font.draw` 的 y 是屏幕左上 | 是基线，世界 y 向上 |
| 键盘用字符/键名直接查 `wag.input` | `wag.input` 用 scancode；键名在 `WagLib.input` |
| 现在能全屏 | 0.2.0 开发中已提供；发行版仍为 0.1.2 |
