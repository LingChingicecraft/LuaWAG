# 窗口与全屏

> 0.2.0 起提供全屏、内部渲染尺寸与呈现控制的脚本入口。
> 全屏只改变输出；逻辑世界仍由 `render` 定义。

---

## 现在能做什么

```lua
wag.space.set_window_size(1280, 720)  -- 请求窗口化尺寸（不是 DIP）
wag.space.get_window_size()           -- 最近请求值；没设过为 nil

wag.space.set_fullscreen("none" | "borderless" | "exclusive")
wag.space.get_fullscreen()

wag.space.set_render_size(640, 480)   -- 内部渲染目标像素尺寸
wag.space.get_render_size()

wag.space.set_present_mode("letterbox" | "stretch")
wag.space.set_present_filter("nearest" | "linear")
wag.space.get_present_mode()
wag.space.get_present_filter()

wag.space.get_frame_size()            -- 当前内部渲染目标像素尺寸
wag.space.get_output_size()           -- 当前输出 / 后缓冲像素尺寸
wag.space.get_display_bounds()        -- { x, y, w, h }
wag.space.get_display_work_area()     -- { x, y, w, h }
```

---

## 四个尺寸

```text
窗口尺寸：
  set_window_size 请求的窗口化客户区尺寸

内部渲染目标：
  set_render_size 决定的离屏画布像素尺寸
  默认 1920×1080
  不自动跟随窗口或全屏输出

输出 / 后缓冲：
  当前窗口或全屏实际输出的像素尺寸
  get_output_size 查询

逻辑 render：
  set_viewport 的 render 矩形，世界的可见范围
```

禁止把它们当成同一个量。

---

## 全屏

```lua
wag.space.set_fullscreen("none")
wag.space.set_fullscreen("borderless")
wag.space.set_fullscreen("exclusive")
```

语义：

```text
none       = 普通窗口
borderless = 覆盖当前显示器完整边界的无边框全屏，不切换显示模式
exclusive  = 独占全屏，使用当前显示器原生模式
```

0.2.0 不做：

```text
显示模式枚举
640×480 等真实显示模式切换
多显示器选择 UI
崩溃后的持久化显示状态恢复
```

独占全屏失败时：

```text
回退窗口模式 + L2
游戏继续运行
```

进入全屏前会保存窗口位置、客户区尺寸、边框；退出时恢复。

全屏切换期间会按住 `fullscreen` 暂停源，避免切换过程被当成正常游戏帧。

## 渲染尺寸

```lua
wag.space.set_render_size(640, 480)
wag.space.set_render_size(1920, 1080)
```

默认：

```text
1920×1080
```

改变的是内部渲染目标，不是窗口尺寸，也不是逻辑 `render`。

比例由宽高推导，不提供独立的 `aspect` 字段。

4:3 是合法配置：

```lua
wag.space.set_render_size(640, 480)
wag.space.set_viewport {
    render = { l = -720, b = -540, w = 1440, h = 1080 },
    strategy = "letterbox",
}
wag.light.set_space {
    l = -720, b = -540, w = 1440, h = 1080,
}
```

光照空间、band mask 和渲染目标的比例需要按同一空间配置。

## 呈现

```lua
wag.space.set_present_mode("letterbox")
wag.space.set_present_mode("stretch")
wag.space.set_present_filter("linear")
wag.space.set_present_filter("nearest")
```

默认：

```text
present_mode   = letterbox
present_filter = linear
```

`stretch` 必须显式选择；引擎不会自动拉满。

4:3 画布在 16:9 输出上默认左右加黑边；
16:9 画布在 4:3 输出上默认上下加黑边。

---

## 单位说明

```text
set_window_size / get_window_size：窗口尺寸（不是 DIP）
set_render_size / get_frame_size：内部渲染目标像素
get_output_size：输出 / 后缓冲像素
```

当前平台没有启用高像素密度时，窗口尺寸与绘制表面像素相等。
这不是“DIP 等于像素”：150% 缩放下，通常意义的物理像素是窗口尺寸 × 1.5。
引擎目前不把 DIP 作为窗口几何输入，也不会自动乘显示比例。

---

## 相关 API

```text
wag.space.set_viewport
wag.space.get_viewport

wag.space.set_window_size
wag.space.get_window_size

wag.space.set_fullscreen
wag.space.get_fullscreen

wag.space.set_render_size
wag.space.get_render_size
wag.space.set_present_mode
wag.space.get_present_mode
wag.space.set_present_filter
wag.space.get_present_filter

wag.space.get_frame_size
wag.space.get_output_size
wag.space.get_display_bounds
wag.space.get_display_work_area
```

`get_window_size()` 是请求值；`get_frame_size()` 是内部渲染尺寸，不是输出尺寸，也不是 DIP。
