# 窗口与全屏

> 当前版本（0.1.x）**没有全屏 API**。
> 本文描述现状、脚本边界，以及 0.2.0 的计划；不是可用接口说明。

---

## 现在能做什么

```lua
wag.space.set_window_size(1280, 720)  -- 请求客户区尺寸
wag.space.get_window_size()           -- 最近请求值；没设过为 nil
wag.space.get_frame_size()            -- 当前帧缓冲像素尺寸
```

窗口由平台层创建为：

```text
OpenGL + 可缩放窗口
```

没有：

```text
独占全屏
无边框窗口全屏
窗口位置控制
显示器枚举 / 显示器边界查询
```

---

## 现在不能做什么

### 不能从脚本进入独占全屏

没有：

```lua
wag.space.set_fullscreen(...)
```

### 不能从脚本做无边框窗口全屏

没有：

```text
set_borderless
set_window_position
get_display_bounds
```

所以“把窗口边缘拉到屏幕外”目前做不到。  
只把 `set_window_size` 设得比屏幕大也不行：窗口位置不受控，标题栏/边框/任务栏仍在。

---

## 0.2.0 计划

计划新增：

```text
独占全屏
无边框窗口全屏
窗口位置 / 显示器边界
全屏切换暂停源
窗口状态恢复
```

设计约束：

- 全屏改变窗口/帧尺寸，不改 `render`；视口仍按 letterbox。
- 全屏切换由“我们的命令”点亮暂停位，不依赖 `WM_ENTERSIZEMOVE`。
- 进入全屏前记录窗口位置、尺寸、边框、显示器；退出时恢复。
- 多显示器默认使用当前窗口所在显示器。
- 无边框全屏要区分显示器完整边界、工作区、DPI 缩放。

---

## 相关 API

当前可用：

```text
wag.space.set_viewport
wag.space.get_viewport
wag.space.set_window_size
wag.space.get_window_size
wag.space.get_frame_size
```

`get_window_size()` 是请求值；`get_frame_size()` 是帧缓冲像素，不是窗口逻辑尺寸。
