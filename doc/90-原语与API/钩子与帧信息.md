## `info` 表的字段

**帧钩子**（`on_frame_*` / `on_render_*` / `on_event` / `on_focus_*`）：

| 字段 | 类型 | 现状 |
|---|---|---|
| `dtg` | number | 恒 `1/60` |
| `frame` | number | 循环帧号；暂停不递增 |
| `dragging` | boolean | 拖拽/缩放窗口（移动与缩放都算） |
| `has_focus` | boolean | 本帧窗口是否有焦点（**真值**，阶段 1 定格） |
| `event` | table \| nil | **本帧事件数组**；无事件 ⇒ `nil` |

事件项的字段：

| `kind` | 额外字段 |
|---|---|
| `key_down` / `key_up` | `scancode`, `repeat` |
| `mouse_move` | `x`, `y` |
| `mouse_down` / `mouse_up` | `button`, `x`, `y` |
| `wheel` | `dx`, `dy` |
| `gamepad_added` / `gamepad_removed` | `device` |
| `gamepad_button_down` / `gamepad_button_up` | `device`, `button` |
| `gamepad_axis` | `device`, `axis`, `value` |

**生命周期钩子**（`on_game_init` / `on_game_exit`）：收到 **空表 `{}`**（没有"本帧"）。

> 全表在每次调用钩子时**重新构造**，但内容来自同一份帧状态 ⇒ 一帧之内所有钩子读到**同一组值**。

## 当前没有的钩子

全屏切换目前**没有**独立的 `on_fullscreen` 钩子；但 0.2.0 已提供
`wag.space.set_fullscreen` / `get_fullscreen`，并把切换过程接成
`pause_source::fullscreen`。

需要响应全屏状态时，脚本自己记录 `get_fullscreen()`，或在每帧的主/扩展钩子里比较变化。

详见 `窗口与全屏.md`。
